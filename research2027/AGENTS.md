# Research2027 Agent Guidance

This project is a new implementation and must remain isolated from the
historical MockingBird files outside this directory.

- Execute one milestone from `PLAN.md` at a time.
- Use PowerShell as the primary shell; do not require Bash.
- Keep model extraction and experiments behind their explicitly authorized
  milestones.
- Prefer synthetic or targeted tests before any expensive run.
- Do not browse the web or spawn subagents during engineering milestones unless
  explicitly requested.
- Update `STATUS.md` at the end of every milestone.
